## 游戏内提示 / Quest Assist

Quest Assist 是可选的游戏内辅助插件。按 **H** 查看任务提示，按 **N** 开关金线导航；小地图也可以在游戏选项里单独关闭。全汉化版请选择对应的专用包，安装说明在 ZIP 内。

Quest Assist is an optional add-on for **Official FINAL**. Press **H** for quest hints or **N** to toggle the gold navigation trail. You can turn off the minimap separately in the game options. Use the **Official FINAL English** package and follow the installation instructions in the ZIP.
